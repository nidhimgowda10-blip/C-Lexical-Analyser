C Lexical Analyzer

Project Overview
A Lexical Analyzer developed using C programming to analyze source code and identify different types of tokens. It performs the initial stage of compiler processing by recognizing keywords, identifiers, operators, constants, and special symbols.

Objectives
- Understand the fundamentals of lexical analysis.
- Identify and classify tokens in C source code.
- Practice string manipulation and file handling in C.
- Gain knowledge of the lexical analysis phase of compiler design.

 Features
- Reads and processes C source code.
- Identifies and classifies supported token types.
- Recognizes keywords and identifiers.
- Detects operators, constants, and special symbols.
- Uses modular programming for organized code implementation.

Technologies Used
- Programming Language: C
- Concepts: Strings, Arrays, File Handling, Tokenization
- Tools: GCC Compiler, Linux/Ubuntu

How to Compile and Run

1. Clone the Repository

cd C-Lexical-Analyzer

2. Compile the Program

gcc *.c -o lexer  # Compile the C source files

3. Run the Program

./lexer  # Execute the lexical analyzer
